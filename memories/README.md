# Mémoire partagée du dépôt

Journal transverse destiné aux agents (et humains) qui travaillent sur ce projet — complément du `CHANGELOG.md` (événements produit) et des ADR (décisions structurantes).

- Un fichier par session ou événement significatif : `YYYY-MM-DD-slug.md`.
- Contenu : décisions prises, apprentissages, pièges, état d'avancement.
- Factuel, concis, daté.
