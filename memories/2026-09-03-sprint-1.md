## Processus (à reproduire)

- 6 agents : moteur, contenu → puis API, interface (en parallèle) → puis 2 revues (exécution E2E réelle, conformité clinique).
- Les agents `run` s'arrêtent parfois après la phase de lecture sans livrer : une relance `sessions_send` avec l'état des lieux exact les fait aboutir (3 relances sur 6 agents).
- Revues : exécution = PRÊT AVEC RÉSERVES ; conformité = 7 OK / 1 écart / réserves mineures. Les 4 constats + 1 écart ont été corrigés avec tests de régression avant commit.
